# 近战配置
> wiki 版本：`0.0.0`.0

路径：`melee`
- `MeleeItemConsumeDurability`（bool）：近战物品攻击时是否消耗耐久
- `MeleeIgnoreInvulnerableTickThreshold`（整数）：当目标的受击无敌时间小于该值时，近战攻击将忽略它
```toml
[melee]
	MeleeItemConsumeDurability = true
	MeleeIgnoreInvulnerableTickThreshold = 20
```

# English
> wiki version: `0.0.0`.0

Path: `melee`
- `MeleeItemConsumeDurability` (bool): Whether melee items consume durability on attack
- `MeleeIgnoreInvulnerableTickThreshold` (integer): When the target's invulnerable tick is less than this value, melee attacks will ignore it
```toml
[melee]
	MeleeItemConsumeDurability = true
	MeleeIgnoreInvulnerableTickThreshold = 20
```
