# 渲染配置
> wiki 版本：`0.0.0`.0

路径：`render`
- `BlackFlash`（bool）：被闪光弹致盲时，是否使用黑色遮罩代替白色遮罩
- `ExplodeScreenShakeMultiplier`（浮点）：爆炸的屏幕晃动系数，默认 1.0
```toml
[render]
	BlackFlash = false
	ExplodeScreenShakeMultiplier = 1.0
```

# English
> wiki version: `0.0.0`.0

Path: `render`
- `BlackFlash` (bool): Use a black overlay instead of a white one when blinded by a flashbang
- `ExplodeScreenShakeMultiplier` (float): Screen shake multiplier for explosions, default is 1.0
```toml
[render]
	BlackFlash = false
	ExplodeScreenShakeMultiplier = 1.0
```
