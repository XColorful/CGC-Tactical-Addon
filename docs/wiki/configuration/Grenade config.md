# 手雷配置
> wiki 版本：`0.0.0`.0

路径：`grenade`
- `GrenadeExplosionBlockDamage`（bool）：手雷爆炸是否可以破坏方块（如果该手雷允许破坏方块）
```toml
[grenade]
	GrenadeExplosionBlockDamage = true
```
